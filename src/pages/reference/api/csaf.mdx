# DevGuard CSAF API

The DevGuard CSAF API serves Common Security Advisory Framework (CSAF) documents for your assets. Reports are generated on demand from your current assessments rather than stored, so a request always reflects the present state.

Beyond the endpoints below, DevGuard serves the full CSAF distribution structure — `provider-metadata.json`, the aggregator listing, per-year indexes, `changes.csv`, and each advisory alongside its OpenPGP signature and checksums. Those paths and how to consume another vendor's provider are documented in [CSAF Reports in DevGuard](/how-to-guides/vulnerability-management/csaf-common-security-advisory-framework).
