# DevGuard Secrets API

The DevGuard Secrets API stores named secret values at three scopes: the organization, a project, or a single repository (asset). Each scope has the same three operations: list, create and delete.

A secret is write-only. You send a `name` and a `value` when you create it, but responses only return its `id`, `name`, `scope` and `inheritedFrom`. The value is never returned. `inheritedFrom` shows which higher scope a secret comes from when you list secrets at a lower one. There is no update operation: to rotate a value, delete the secret and create it again.

These endpoints manage secrets stored in DevGuard. They are unrelated to [secret scanning](/reference/github-workflows/secret-scanning), which finds leaked credentials in your source code.
