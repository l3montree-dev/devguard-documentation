# DevGuard Labels API

The DevGuard Labels API lets you define labels and attach them to artifacts. You can create a label at the organization, project or asset level. Each level supports listing, creating, updating and deleting labels.

A label has a `label` name, a `description` and a `backgroundColor` given as a hex color such as `#1f6feb`. To tag an artifact, send one or more label names in the `label` array of an `attach` request.
